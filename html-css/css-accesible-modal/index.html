Título da Modal

Este é um exemplo de modal criado apenas com CSS, sem JavaScript. A técnica utilizada é conhecida como "checkbox hack".

Funcionalidades incluídas:

  • Animação de abertura/fechamento suave
  • Overlay escuro semi-transparente
  • Responsividade para mobile
  • Foco na acessibilidade
  • Botão de fechar intuitivo

Conteúdo da página

Esta é a página principal. Quando você abre a modal, o conteúdo fica escurecido pelo overlay, mas continua visível.
